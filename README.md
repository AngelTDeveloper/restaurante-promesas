# 🍽️ Simulación de Entrega de Órdenes en Restaurante

Simulador interactivo de entrega de órdenes en tiempo real desarrollado en **JavaScript (ES6)** utilizando **Promesas** (`Promises` y `async/await`) para garantizar un flujo de preparación y entrega estrictamente secuencial: **Bebida ➔ Pizza ➔ Postre**.

## ✨ Características

- **Procesamiento Secuencial Asíncrono:** Implementación rigurosa de Promesas para asegurar que cada platillo se entregue en el orden correcto.
- **Interfaz Cyberpunk / Neon Retro:** Diseño moderno basado en *Glassmorphism*, fuentes personalizadas y efectos de luz ambiental.
- **Consola Interactiva en Pantalla:** Una terminal integrada que intercepta y muestra los eventos y logs del proceso en tiempo real.
- **Indicadores Visuales:** Tarjetas dinámicas que actualizan su estado gráfico (*En espera*, *Preparando*, *Entregado*).

## 📁 Estructura del Proyecto

El código está dividido en tres archivos independientes para mantener una arquitectura limpia:


├── index.html    # Estructura principal de la interfaz web
├── styles.css    # Estilos visuales y animaciones (Tema Cyberpunk)
└── script.js     # Lógica de asincronía, Promesas y manipulación del DOM (ES6)

## 🚀 Tecnologías Utilizadas

* **HTML5**
* **CSS3** (Flexbox, CSS Grid, Backdrop Filter, Animaciones Custom)
* **JavaScript (ES6+)** (`async/await`, Promesas, Funciones Flecha, Event Listeners)

## ⚙️ Cómo Ejecutar el Proyecto

1. Clona este repositorio o descarga los tres archivos (`index.html`, `styles.css` y `script.js`) dentro de una misma carpeta en tu computadora.
2. Abre el archivo `index.html` directamente en tu navegador web preferido (Google Chrome, Edge, Firefox, etc.).
3. Haz clic en el botón **"Iniciar Orden"** para poner en marcha la simulación de cocina.
